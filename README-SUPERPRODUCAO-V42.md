# CyberShield Superprodução V42

V42 transforma os artworks fornecidos em capítulos interativos reais.

## O que mudou
- cada página recebe um capítulo cinematográfico próprio baseado no artwork correspondente;
- o artwork aparece como cenário dominante e também como painel explorável;
- hotspots contextuais mudam a leitura do cenário;
- áudio dedicado de cada universo é carregado localmente e só inicia após ação do usuário;
- a Cadeia de Ataque usa o artwork canônico em português dos sete estágios;
- parallax usa apenas transform para manter o custo baixo;
- reduced-motion, foco por teclado e fallback da navegação permanecem;
- o conteúdo original das páginas é preservado.
