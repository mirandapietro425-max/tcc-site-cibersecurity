# CyberShield — Superprodução V41

Pacote de integração visual e sonora construído sobre a V38 FINAL, com Radar V39 e Playbook V40.

## O que foi adicionado
- camada cinematográfica por página usando os novos visuais entregues;
- áudio ambiente opcional por página;
- transições MPA progressivas com View Transition API quando disponível;
- parallax leve, desativado em reduced-motion/coarse pointer;
- Radar V39;
- Playbook V40;
- mapa dos sete estágios em português na Cadeia de Ataque;
- assets em `assets/superproduction-v41/`.

## Regra de integração
Preservar a arquitetura atual. Os upgrades V41 são camadas aditivas e não substituem componentes funcionais das páginas sem comparação.

## Áudio
Autoplay não é forçado. O visitante ativa o som pelo controle existente ou pelo controle V41.
