# CyberShield V61 — Hexad Cinematográfico

Esta versão muda a experiência de uma sequência de seções independentes para uma direção narrativa contínua.

- Um renderer WebGL e um único requestAnimationFrame.
- Câmera dirigida pela posição do scroll.
- Seis mundos 3D reais carregados e animados.
- Drone, núcleo, fragmento e satélites como elementos vivos da cena.
- Vídeos de gênese, colapso e restauração como plates narrativas.
- Interações com consequência de estado.
- Narração preparada em faixas independentes.
- Mobile com rail de forças em uma coluna e controles grandes.
- Fallback 2D se WebGL falhar.
