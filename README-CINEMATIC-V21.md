# CyberShield Interactive V21

Esta versão substitui o conjunto abstrato anterior por cinco assets tangíveis e semanticamente claros:

1. `user_human.glb` — usuário/desenvolvedor
2. `security_laptop.glb` — phishing, autenticação e desenvolvimento
3. `attack_robot.glb` — malware/ameaça
4. `enterprise_server.glb` — infraestrutura/API/backend
5. `digital_vault.glb` — proteção de dados/defesa

A cena mantém a narrativa do TCC e usa os modelos como objetos narrativos, enquanto partículas, iluminação e câmera permanecem como elementos auxiliares.

Abra com Live Server ou `python -m http.server 5500`.
