# Arquivos legados

Este diretório contém versões históricas retiradas do caminho de produção. Elas não são carregadas por nenhuma entrada ativa do site.

A pasta `legacy/hexad/` preserva as versões V60, V61, V72, V82 e V90 da experiência Hexad. A entrada atual é `hexad.html`, que carrega somente `hexad.css` e `hexad.js`.

Não adicionar novas correções aqui. Para mudanças futuras, editar o arquivo ativo consolidado e registrar a alteração no histórico Git.
