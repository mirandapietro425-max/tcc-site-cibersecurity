CyberShield Interactive V20

Esta versão usa o novo conjunto coerente de cinco objetos 3D: personagem/usuário, notebook, robô atacante, servidor e cofre digital. A narrativa mantém os conceitos do TCC e os objetos são tangíveis e semanticamente claros.

Objetos por cena:
01 personagem — usuário
02 notebook — phishing/engenharia social
03 robô atacante — ameaça/malware
04 servidor — cadeia de ataque e desenvolvimento seguro
05 cofre digital — defesa em profundidade e proteção de dados
06 cofre digital — dado protegido/LGPD
07 servidor — infraestrutura/código
08 personagem — recuperação

Abra com Live Server ou `python -m http.server 5500` para que os módulos Three.js e os GLB sejam carregados corretamente.
