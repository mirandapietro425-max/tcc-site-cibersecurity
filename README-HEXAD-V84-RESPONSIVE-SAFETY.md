# CyberShield HEXAD V84 — Responsive Safety

V84 endurece a versão V83 com:
- margens de colisão maiores em desktop;
- zonas seguras adicionais entre copy e módulos laterais;
- composição mobile mais robusta;
- safe-area e alvos touch;
- loader sem bloquear visualmente a primeira imagem;
- fallback de frame preservado;
- primeiro frame independente do boot do WebGL.

Limitação: esta entrega foi validada estruturalmente e por sintaxe; screenshot pixel-a-pixel em Chromium não foi concluído neste ambiente.
