# CyberShield V19

V19 reequilibra a linguagem 3D: remove os assets abstratos novos das cenas e volta a usar objetos narrativos claros (avatar, terminal, robô de ameaça, servidor, núcleo de defesa, banco de dados e infraestrutura).

Também fixa a hierarquia visual: canvas 3D no fundo, conteúdo em camada superior com contraste e blur; interação por clique permanece nos elementos UI.

A animação textual passa a acompanhar continuamente o progresso local do scroll, com entrada, permanência e saída sincronizadas.
