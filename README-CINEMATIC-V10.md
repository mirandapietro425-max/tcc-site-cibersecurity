# CyberShield — Cinematic Interactive V10

V10 preserves the V8/V9 experience and adds a real 3D asset layer using the supplied GLB models.

## Added
- Scroll-driven camera movement and depth choreography.
- Supplied GLB models loaded per chapter with Three.js GLTFLoader.
- Clickable 3D models mapped to TCC topics.
- Scene labels and global experience map.
- Progress rail synchronized with scroll.
- Model-aware mobile degradation and reduced-motion fallback.

## Local 3D assets
- character_avatar.glb
- computer_terminal.glb
- server_environment.glb
- database_core.glb
- defense_core.glb
- threat_robot.glb

The experience still uses Three.js, GSAP, Lenis and the supplied audio assets.
