# CyberShield HEXAD V81 — Image-First Film

Esta versão corrige a hierarquia visual do filme.

## Regra principal
As 98 imagens autorais do storyboard são a camada visual principal desde a entrada da página e durante o modo filme. O WebGL fica restrito a contexto/profundidade, com opacidade reduzida.

## Correções
- storyboard fullscreen dominante por padrão;
- 3D reduzido a camada contextual;
- vídeo cinematográfico reduzido a uma camada de acontecimento, sem cobrir a imagem principal;
- sincronização dos frames continua dirigida por `STORYBOARD_SEQUENCE` e pelo relógio narrativo;
- thumbnail `074.webp` regenerada a partir do frame íntegro 074;
- indicação discreta de que o filme está em modo visual/98 frames;
- comportamento mobile preservado, com intensidade menor de contexto 3D.

## Princípio UX
A imagem é a protagonista. Áudio conduz tempo e sentido. 3D dá espacialidade. Vídeo entra apenas como acontecimento.
