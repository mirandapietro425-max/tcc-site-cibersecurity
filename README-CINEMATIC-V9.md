# CyberShield Cinematic V9 — Interactive Worlds

V9 mantém a base audiovisual da V8 e adiciona uma camada de exploração contextual.

## O que foi acrescentado

- hotspots interativos dentro de cada universo;
- painel lateral de exploração com conteúdo contextual;
- hotspots 3D no WebGL que podem ser clicados;
- navegação por teclado (Escape para fechar o painel);
- feedback sonoro nas interações;
- indicação discreta de que a cena pode ser explorada;
- preservação do preloader, áudio, scroll, WebGL e narrativa da V8.

## Conteúdo

As informações exibidas nos hotspots derivam dos temas do TCC fornecido: CID, engenharia social, phishing, malware, ransomware, APIs, Source Maps, defesa em profundidade, menor privilégio, LGPD, accountability, SAST, validação no servidor, resposta a incidentes e recuperação.

## Execução

Abra `index.html` com conexão à internet para carregar as bibliotecas Three.js, GSAP e Lenis via CDN.
