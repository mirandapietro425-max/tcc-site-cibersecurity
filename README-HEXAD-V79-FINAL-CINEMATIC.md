# CyberShield HEXAD V79 — Filme real com 98 frames

Base: V78 REAL FILM UX + entrega completa de assets.

## Mudanças principais
- As 98 imagens autorais em 2560×1440 foram incorporadas como a camada visual principal do modo FILME.
- Sequência temporal recalculada a partir da nomenclatura/ordem dos 98 arquivos e das durações reais dos 8 áudios.
- Os 8 áudios finais foram renomeados de forma determinística para narration-01.mp3 ... narration-08.mp3.
- O clique ASSISTIR FILME ativa o modo filme, habilita o áudio, inicia a narração e mantém a timeline sincronizada.
- O 3D fica em baixa opacidade/contexto durante o filme para não disputar com as imagens.
- Crossfade/slow zoom continua entre frames; existe parallax suave no desktop.
- Memória Visual utiliza os mesmos frames reais.
- Vídeos e microcinemáticas disponíveis foram integrados preservando os nomes reais.
- Ambiências e SFX disponíveis foram incorporados.
- Botões finais ficam explicitamente interativos.

## Sequência narrativa
A duração mestre é 376,659 s. Os 8 arquivos de voz são usados como relógio narrativo:

## Regra de direção
Imagem = protagonista.
3D = espaço/contexto.
Vídeo = acontecimento especial.
Áudio = relógio temporal.
Interação = investigação.
