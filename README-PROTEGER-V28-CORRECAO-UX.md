# Protege V28 — correção de composição e distância

A Protege foi simplificada para corrigir os problemas visuais relatados:
- área da experiência reduzida, eliminando o vazio preto excessivo;
- composição em largura controlada e sem overflow horizontal;
- removidas órbitas, bolas, grid/scanline e imagem fallback sobreposta;
- apenas o personagem/modelo 3D atual permanece como elemento visual principal;
- personagem aproximado da área de conteúdo e com escala mais contida;
- mapa de defesa aproximado da parte inferior, sem ocupar uma coluna distante;
- clique nas camadas não abre mais um modal que esconde a experiência: ele apenas troca a cena;
- preservada a seção de conclusão, mas com menor espaçamento inicial;
- modelos antigos continuam no pacote, porém não são usados como composição visual adicional na Protege.
